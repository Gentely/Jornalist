## 💳 تدفق الدفع / Payment Flow

- **الخيار (أ) — تحويل مصرفي:** صفحة الدفع ← زر **«حساب الدفع»** ← نافذة زرقاء `#EFF6FF` تعرض اسم صاحب الحساب ورقم الحساب والايبان مع أيقونات نسخ وأزرار (نسخ رقم الحساب / نسخ الايبان / تم) + سطر «المصرف: مصرف الجمهورية - المدينة - صبراتة» ← العميل يحوّل ثم **يرفع صورة الإيصال (إلزامي)** ← الحالة: **قيد المراجعة** ← الإدارة تعتمد/ترفض من `/admin` ← الاعتماد يفتح التحميل في `/my-orders`.
- **الخيار (ب) — واتساب (الزر الأخضر الرئيسي):** «إتمام الطلب عبر واتساب 00218918199601» يفتح `https://wa.me/218918199601?text=...` مع تفاصيل السلة جاهزة.
- زر واتساب عائم في **أسفل يسار** كل الصفحات.

## 🗄️ Supabase (للانتقال للإنتاج)

1. أنشئ مشروعاً في [supabase.com](https://supabase.com) ونفّذ `supabase/schema.sql` في SQL Editor.
2. أنشئ Storage buckets: `covers` (عام)، `research-files` (خاص)، `receipts` (خاص).
3. انسخ `.env.example` إلى `.env.local` وضع `NEXT_PUBLIC_SUPABASE_URL` و `NEXT_PUBLIC_SUPABASE_ANON_KEY`.
4. بعده يعمل تسجيل الدخول فوراً؛ والتحميلات تُقدَّم بروابط موقّعة بعد اعتماد الطلب.
